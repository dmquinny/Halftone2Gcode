Pen Pressure Calibration Guide

Step 1: Set Lightest Pressure Z Height

In the "Lightest Pressure (Z)" field, enter a Z height value (e.g., 0mm).

This is where your pen barely touches the paper.

Step 2: Draw Test Line at Light Pressure

1. Send a simple horizontal line G-code to your plotter using the Z height from Step 1

2. Use scrap material (paper or cardboard)

3. Observe the line width on the paper

Step 3: Measure the Light Pressure Line

Use calipers or ruler to measure the actual width of the line you drew.

Example: If the line is 0.3mm wide, you'll enter 0.3 in the next field.

⚠️ Measure carefully - this is critical for calibration!

Step 4: Enter Light Pressure Line Width

Enter the measured width in the "Line Width at Light Pressure (mm)" field.

This is the thinnest line your pen can draw.

Step 5: Set Heaviest Pressure Z Height

In the "Heaviest Pressure (Z)" field, enter a Z height value (e.g., -0.5mm).

This is where your pen presses hardest into the paper.

Step 6: Draw Test Line at Heavy Pressure

1. Send the same horizontal line G-code using the Z height from Step 5

2. Use the same scrap material next to the first line

3. Observe the line width

Step 7: Measure the Heavy Pressure Line

Use calipers or ruler to measure the width of this second line.

Example: If the line is 1.5mm wide, you'll enter 1.5 in the next field.

⚠️ Use the same measurement tool for consistency!

Step 8: Enter Heavy Pressure Line Width

Enter the measured width in the "Line Width at Heavy Pressure (mm)" field.

This is the thickest line your pen can draw.

✓ Calibration Complete!

The system now knows the relationship between Z pressure and line width for your setup.

When you generate halftones, it will automatically scale line widths based on brightness.
